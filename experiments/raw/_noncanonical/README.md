# Non-canonical raw exports

This directory preserves exports that are related to the project but were not
used to produce the official processed datasets or the integrated 690-run
analysis.

`MOSAIC_BS01_Baseline_PerStep_Export_Not_Used.csv` records metrics at multiple
time steps. The canonical BS01 export records final metrics only and is stored
under `raw/BS01_Baseline_Replication/`.
