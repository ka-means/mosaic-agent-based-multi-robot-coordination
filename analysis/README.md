# MOSAIC Analysis Files

This directory contains the experiment-specific statistical workbooks and the
integrated BS01–BS07 analysis.

The primary synthesis file is:

`MOSAIC_BS01_BS07_Integrated_Analysis.xlsx`

The `previews/` directory contains selected workbook-render previews. The
workbooks are derived products; the canonical evidence remains the raw
BehaviorSpace exports and clean CSV files under `experiments/`.
