# MOSAIC v0.4.0 Technical Report

This directory contains the final pre-publication Technical Report for the
MOSAIC v0.4.0 model and its integrated statistical evaluation.

## Files

- `MOSAIC_v0.4.0_Technical_Report.pdf` — publication-quality report
- `MOSAIC_v0.4.0_Technical_Report.docx` — editable source document

The report follows an academic document structure, incorporates an ODD-aligned
model specification, evaluates all seven hypotheses, and reports evidence from
690 official simulation runs.
