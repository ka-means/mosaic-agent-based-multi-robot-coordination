# MOSAIC Master Dataset — Data Dictionary

The canonical harmonized dataset is:

`processed/MOSAIC_All_Experiments_Master_Runs.csv`

## Identification and experimental design

| Field | Definition |
|---|---|
| Experiment | BehaviorSpace experiment identifier, BS01–BS07. |
| Experiment Name | Human-readable experiment name. |
| Condition | Human-readable condition label. |
| Run | Sequential run identifier within the source experiment. |
| Seed | Random seed used for paired comparisons. |
| Factor 1 | Name of the primary manipulated factor. |
| Factor 1 Level | Level of the primary manipulated factor. |
| Factor 2 | Name of the secondary manipulated factor, when applicable. |
| Factor 2 Level | Level of the secondary manipulated factor, when applicable. |

## Mission and task outcomes

| Field | Definition |
|---|---|
| Ticks | Mission duration in model ticks. |
| Completed Tasks | Number of tasks completed successfully. |
| Failed Tasks | Number of tasks terminating in failure. |
| Completion Rate (%) | Completed tasks divided by total tasks, expressed as a percentage. |
| Discovered Completion (%) | Completed discovered tasks divided by all discovered tasks. |
| Explored Area (%) | Share of world patches explored by robots. |
| Individual Tasks | Number of tasks not requiring a coalition. |
| Cooperative Tasks | Number of tasks requiring a coalition. |
| Completed Cooperative Tasks | Number of cooperative tasks completed successfully. |

## Auctions, contracts, and coalitions

| Field | Definition |
|---|---|
| Total Bids | Cumulative number of auction bids submitted. |
| Unresolved Auction Rounds | Auction rounds that did not produce a feasible assignment. |
| Contracts Awarded | Number of task contracts awarded. |
| Contract Releases | Contracts released before successful completion. |
| Coalition Attempts | Cumulative cooperative coalition-formation attempts. |
| Coalitions Formed | Number of coalitions successfully formed. |
| Coalition Success (%) | Completed cooperative tasks divided by coalitions formed, expressed as a percentage. |
| Coalition Formation Efficiency (%) | Coalitions formed divided by coalition-formation attempts, expressed as a percentage. |
| Mean Coalition Delay | Mean time between cooperative-task discovery and coalition formation. |

## Economic outcomes

| Field | Definition |
|---|---|
| Task Value | Total base value of successfully completed tasks. |
| Rewards Distributed | Total credits distributed to robots. |
| Mission Bonuses | Additional rewards generated by the mission-incentive rule. |
| Reward Gini | Gini coefficient of robot credit outcomes. |
| Contract Gini | Gini coefficient of contract allocation across robots. |
| Top 20% Reward Share (%) | Percentage of total rewards received by the highest-reward quintile. |

## Information, learning, and efficiency

| Field | Definition |
|---|---|
| Information Coverage (%) | Share of task information acquired by the robot population. |
| Mean Reputation | Mean robot reputation at mission termination. |
| Strategy Switches | Total adaptive strategy changes during the mission. |
| Coordination Overhead | Composite measure of coordination activity relative to mission output. |
| Mission Efficiency | Mission output relative to coordination expenditure. |
| Energy Used | Total robot energy consumed. |
| Energy Remaining | Total robot energy remaining at termination. |

## Failure decomposition

| Field | Definition |
|---|---|
| Failed — Undiscovered | Tasks that failed without being discovered. |
| Failed — Auction/No Feasible | Failures caused by no feasible bid, no feasible coalition, or unresolved auction. |
| Failed — Deadline After Assignment | Tasks that failed after assignment because the deadline expired. |
| Failed — Other | Remaining failure reasons not included in the preceding categories. |

## Recorded run-level verification

| Field | Definition |
|---|---|
| Task State Pass | True when no task is simultaneously completed and failed. |
| Energy Error | Absolute energy-accounting residual. |
| Reward Error | Absolute reward-accounting residual. |
| Reputation Bounds Pass | True when all reputation values remain in [0, 1]. |
| Strategy Validity Pass | True when every robot has a permitted strategy. |

The model's manual `RUN CHECKS` procedure also evaluates contract consistency,
coalition membership, failure traceability, and knowledge integrity.
